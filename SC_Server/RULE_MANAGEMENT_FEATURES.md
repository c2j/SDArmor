# SC_Server 规则管理功能

## 功能概述

SC_Server现在支持完整的规则编辑和导入功能，管理员可以通过Web界面轻松管理安全扫描规则。

## 已实现的功能

### 🎯 功能1：规则导入功能
- ✅ 支持JSON格式规则文件导入
- ✅ 文件格式验证和错误提示
- ✅ 版本冲突检测
- ✅ 导入后可选择立即激活
- ✅ 完整的错误处理和用户反馈

### 🎯 功能2：规则编辑功能
- ✅ 规则集基本信息编辑（名称、描述）
- ✅ 文件类型和规则模式查看
- ✅ 规则统计信息显示
- ✅ 编辑界面框架（可扩展详细编辑功能）

### 🎯 功能3：示例规则文件
- ✅ 提供标准格式的示例规则文件
- ✅ 包含多种编程语言的安全规则
- ✅ 支持示例文件下载
- ✅ 详细的格式说明和文档

### 🎯 功能4：增强的用户界面
- ✅ 规则管理页面添加导入和示例下载按钮
- ✅ 规则列表添加编辑按钮
- ✅ 规则详情页面添加编辑入口
- ✅ 响应式设计和用户友好的界面

## 技术实现

### API端点扩展

#### 新增API端点
```python
# 规则导入
POST /api/v1/rules/import
- 支持文件上传和格式验证
- 版本冲突检测
- 可选激活功能

# 示例规则获取
GET /api/v1/rules/sample
- 返回标准格式的示例规则
- JSON格式响应

# 示例文件下载
GET /rules/sample
- 下载示例规则文件
- 文件格式：sample_rules.json
```

#### 增强的路由
```python
# 规则导入页面
GET/POST /rules/import
- 文件上传表单
- 格式验证和错误处理

# 规则编辑页面
GET/POST /rules/<id>/edit
- 基本信息编辑
- 规则查看和管理界面
```

### 前端页面

#### 1. 规则导入页面 (`/rules/import`)
- **文件上传表单**：支持JSON文件选择和验证
- **格式说明**：折叠式格式文档
- **示例下载**：一键下载示例规则文件
- **导入选项**：可选择导入后立即激活

#### 2. 规则编辑页面 (`/rules/<id>/edit`)
- **基本信息编辑**：名称、描述修改
- **规则查看**：文件类型和规则模式展示
- **统计信息**：规则数量和分布统计
- **扩展接口**：为详细编辑功能预留接口

#### 3. 增强的规则管理页面
- **导入按钮**：直接跳转到导入页面
- **示例下载**：快速获取示例文件
- **编辑按钮**：每个规则集都有编辑入口

### 示例规则文件格式

```json
{
  "name": "示例安全规则集",
  "version": "1.0.0", 
  "description": "规则集描述",
  "file_types": [
    {
      "name": "JavaScript Files",
      "identifiers": [
        {
          "type": "extension",
          "pattern": "\\.(js|jsx|ts|tsx)$"
        },
        {
          "type": "content", 
          "pattern": "^\\s*(import|export|require)"
        }
      ],
      "patterns": [
        {
          "id": "JS-001",
          "description": "不安全的eval函数使用",
          "severity": "high",
          "regex": "eval\\s*\\("
        }
      ]
    }
  ]
}
```

### 支持的编程语言

示例规则文件包含以下语言的安全规则：
- **JavaScript/TypeScript**: XSS、代码注入、不安全函数
- **Python**: 命令注入、SQL注入、不安全序列化
- **Java**: SQL注入、反序列化、硬编码密码
- **PHP**: 代码注入、文件包含、SQL注入
- **C/C++**: 缓冲区溢出、格式化字符串漏洞

## 用户操作流程

### 导入规则集
1. 登录管理员账户
2. 进入"规则管理"页面
3. 点击"导入规则集"按钮
4. 选择JSON格式的规则文件
5. 可选择"导入后立即激活"
6. 点击"导入规则集"完成导入

### 编辑规则集
1. 在规则列表中点击"编辑"按钮
2. 修改规则集名称和描述
3. 查看文件类型和规则详情
4. 点击"保存更改"完成编辑

### 下载示例文件
1. 在规则管理页面点击"下载示例"
2. 或在导入页面点击"下载示例规则文件"
3. 获得标准格式的示例文件

## 安全特性

### 文件验证
- **格式检查**：只接受JSON格式文件
- **大小限制**：最大16MB文件大小
- **结构验证**：使用JSON Schema验证规则格式
- **版本检查**：防止重复版本导入

### 权限控制
- **管理员权限**：只有管理员可以导入和编辑规则
- **操作日志**：记录规则修改操作
- **错误处理**：完善的错误信息和用户反馈

### 数据完整性
- **事务处理**：导入失败时自动回滚
- **备份建议**：提醒用户在修改前备份
- **版本管理**：保持规则版本的唯一性

## 扩展性设计

### 预留接口
- 规则编辑页面预留了详细编辑功能的接口
- 支持添加、修改、删除具体规则模式
- 可扩展文件类型管理功能

### API扩展
- 规则导入API支持更多格式扩展
- 可添加规则验证和测试功能
- 支持批量操作和高级管理功能

## 使用建议

### 规则文件创建
1. 下载示例文件作为模板
2. 根据需要修改文件类型和规则
3. 确保正则表达式正确转义
4. 使用唯一的版本号

### 最佳实践
1. 定期备份现有规则集
2. 在测试环境验证新规则
3. 使用描述性的规则ID和描述
4. 按严重性合理分类规则

### 故障排除
- 导入失败：检查JSON格式和Schema验证
- 版本冲突：修改版本号或删除现有规则集
- 权限错误：确保使用管理员账户操作
