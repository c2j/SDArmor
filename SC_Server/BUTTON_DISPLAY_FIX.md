# 按钮文字显示问题修复

## 🐛 问题描述

用户反馈页面上的操作按钮等各种按钮看不到文字，只能看到按钮轮廓但没有内容。

## 🔍 问题分析

### 可能的原因
1. **只有图标没有文字**: 按钮只包含Bootstrap图标，没有文字内容
2. **图标字体未加载**: Bootstrap Icons字体文件加载失败
3. **CSS样式问题**: 文字颜色与背景色相同或字体大小为0
4. **字体路径错误**: 静态文件路径配置问题

### 检查发现的问题
原始按钮代码只包含图标，没有文字：
```html
<!-- 问题代码 -->
<a href="#" class="btn btn-sm btn-info">
    <i class="bi bi-eye"></i>  <!-- 只有图标 -->
</a>
```

## ✅ 修复方案

### 1. 为所有按钮添加文字内容
确保每个按钮都有可读的文字，即使图标不加载也能理解功能：

```html
<!-- 修复后 -->
<a href="#" class="btn btn-sm btn-info" title="查看详情">
    <i class="bi bi-eye"></i> 查看  <!-- 图标 + 文字 -->
</a>
```

### 2. 添加CSS样式确保文字可见
```css
/* 确保按钮文字可见 */
.btn {
    font-weight: 500;
    color: inherit;
}

.btn i {
    margin-right: 0.25rem;
}

/* 当图标字体未加载时的后备样式 */
.btn i:before {
    content: "";
}
```

## 📱 响应式考虑

### 小屏幕适配
在小屏幕上，可以考虑只显示图标：
```css
@media (max-width: 576px) {
    .btn-sm .btn-text {
        display: none;
    }
}
```
