# SC_Server 规则编辑和导入功能演示

## 🎯 功能概述

SC_Server现在支持完整的规则编辑和导入功能，管理员可以通过Web界面轻松管理安全扫描规则，并提供了标准的示例规则文件格式。

## ✨ 新增功能

### 1. 规则导入功能
- **文件上传**: 支持JSON格式规则文件导入
- **格式验证**: 自动验证规则文件格式和结构
- **版本检查**: 防止重复版本导入
- **即时激活**: 导入后可选择立即激活规则集

### 2. 规则编辑功能
- **基本信息编辑**: 修改规则集名称和描述
- **规则查看**: 查看文件类型和规则模式详情
- **统计信息**: 显示规则数量和分布
- **扩展接口**: 为详细编辑功能预留接口

### 3. 示例规则文件
- **多语言支持**: JavaScript、Python、Java、PHP、C/C++
- **标准格式**: 符合系统要求的JSON格式
- **安全规则**: 包含常见安全漏洞检测规则
- **一键下载**: 直接从界面下载示例文件

## 🚀 使用演示

### 步骤1: 访问规则管理页面
```
URL: http://127.0.0.1:5000/rules
功能: 查看所有规则集，包含新增的导入和编辑按钮
```

### 步骤2: 下载示例规则文件
```
操作: 点击"下载示例"按钮
结果: 获得包含5种编程语言、23个安全规则的示例文件
文件: sample_rules.json
```

### 步骤3: 导入规则集
```
URL: http://127.0.0.1:5000/rules/import
操作: 
1. 选择JSON格式的规则文件
2. 可选择"导入后立即激活"
3. 点击"导入规则集"
验证: 系统自动验证文件格式和版本唯一性
```

### 步骤4: 编辑规则集
```
操作: 在规则列表中点击"编辑"按钮
功能:
1. 修改规则集名称和描述
2. 查看文件类型和规则详情
3. 查看规则统计信息
4. 保存更改
```

## 📋 示例规则文件格式

### 基本结构
```json
{
  "name": "示例安全规则集",
  "version": "1.0.0",
  "description": "规则集描述",
  "file_types": [...]
}
```

### 文件类型定义
```json
{
  "name": "JavaScript Files",
  "identifiers": [
    {
      "type": "extension",
      "pattern": "\\.(js|jsx|ts|tsx)$"
    },
    {
      "type": "content",
      "pattern": "^\\s*(import|export|require)"
    }
  ],
  "patterns": [...]
}
```

### 规则模式
```json
{
  "id": "JS-001",
  "description": "不安全的eval函数使用",
  "severity": "high",
  "regex": "eval\\s*\\("
}
```

## 🔧 API端点

### 新增API
```
GET  /api/v1/rules/sample     - 获取示例规则JSON
POST /api/v1/rules/import     - 导入规则文件
GET  /rules/sample            - 下载示例规则文件
```

### 页面路由
```
GET  /rules/import            - 规则导入页面
POST /rules/import            - 处理规则导入
GET  /rules/<id>/edit         - 规则编辑页面
POST /rules/<id>/edit         - 保存规则修改
```
