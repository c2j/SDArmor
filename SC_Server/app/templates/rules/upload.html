规则集格式说明

规则集必须是有效的JSON文件，包含以下结构：

{
  "version": "1.0.0",
  "file_types": [
    {
      "name": "JavaScript",
      "identifiers": [
        {
          "type": "extension",
          "pattern": "\\.js$"
        }
      ],
      "patterns": [
        {
          "id": "js-001",
          "description": "不安全的eval使用",
          "severity": "high",
          "regex": "eval\\(.*\\)"
        }
      ]
    }
  ]
}

每个文件类型可以包含多个标识符和多个模式。

严重性级别必须是以下之一：

  • critical - 严重漏洞
  • high - 高危漏洞
  • medium - 中危漏洞
  • low - 低危漏洞
