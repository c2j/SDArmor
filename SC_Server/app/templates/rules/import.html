规则文件格式

规则文件必须是有效的JSON格式，包含以下结构：

{
  "name": "规则集名称",
  "version": "1.0.0",
  "description": "规则集描述",
  "file_types": [...]
}

{
  "name": "JavaScript",
  "identifiers": [
    {
      "type": "extension",
      "pattern": "\\.js$"
    }
  ],
  "patterns": [...]
}

{
  "id": "JS-001",
  "description": "不安全的eval使用",
  "severity": "high",
  "regex": "eval\\(.*\\)"
}

严重性级别： critical, high, medium, low
