# SD Armor Development Scripts

This directory contains various scripts to help with development, deployment, and maintenance of SD Armor.

## Script Categories

### Development Scripts (`devops/`)
Scripts for development environment setup and daily development tasks.

### Deployment Scripts (`deployment/`)
Scripts for deploying SD Armor to various environments.

### Utility Scripts (`utils/`)
General utility scripts for maintenance and automation.

## Usage

Most scripts can be run directly from the command line:

```bash
# Example
./scripts/devops/setup-dev-env.sh
```

## Contributing

When adding new scripts:
1. Place them in the appropriate subdirectory
2. Make them executable (`chmod +x script-name.sh`)
3. Add documentation at the top of the script
4. Follow the existing naming conventions
